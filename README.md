Мобильное Android-приложение для управления календарём и расписанием.  
Приложение позволяет создавать, редактировать и удалять события, а также хранить данные в Firebase и синхронизировать их между устройствами.

Возможности

- Авторизация пользователей.
- Создание и редактирование событий.
- Просмотр расписания по датам.
- Удаление событий.
- Хранение данных в Firebase.
- Работа по архитектуре MVVM.

Технологии

- Java
- Android SDK
- Firebase Authentication
- Firebase Firestore / Realtime Database
- ViewModel
- LiveData
- ViewBinding

Установка

1. Склонируйте репозиторий:

git clone https://github.com/your-username/my-calendar.git


2. Откройте проект в Android Studio.

3. Подключите Firebase:
- создайте проект в Firebase Console;
- добавьте Android-приложение;
- скачайте `google-services.json` и поместите его в папку `app/`.

4. Синхронизируйте Gradle и запустите приложение на эмуляторе или устройстве.

## Конфигурация Firebase

Перед запуском убедитесь, что:
- включена аутентификация Firebase;
- настроена база данных Firestore или Realtime Database;
- добавлены необходимые правила доступа.

## Использование

1. Зарегистрируйтесь или войдите в аккаунт.
2. Добавьте новое событие в календарь.
3. Просматривайте расписание по датам.
4. Редактируйте или удаляйте события при необходимости.

## Архитектура

Приложение построено по принципам MVVM:
- Activity и Fragment отвечают за отображение интерфейса;
- ViewModel управляет состоянием экрана;
- Repositor отвечает за работу с данными;
- Firebase используется как облачное хранилище.
